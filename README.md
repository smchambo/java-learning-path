# Java Learning Path

> A structured Java learning roadmap focused on software engineering fundamentals, problem solving, clean code, and modern Java practices.

---

# Overview

This repository contains a progressive collection of Java exercises designed to teach:

- Java syntax and fundamentals
- Object-Oriented Programming (OOP)
- Collections Framework
- Exception handling
- File processing
- Java 8+ features
- Data structures and algorithms
- Software engineering practices

The goal is not only to learn Java, but also to learn how to think and work like a professional software engineer.

---

# Learning Philosophy

This repository follows a progressive engineering-oriented approach:

| Phase | Focus |
|---|---|
| Phase 1 | Learn programming fundamentals |
| Phase 2 | Learn modularization and structure |
| Phase 3 | Learn object-oriented design |
| Phase 4 | Learn APIs and collections |
| Phase 5 | Learn modern Java |
| Phase 6 | Learn algorithms and engineering thinking |

Exercises evolve gradually from:
- beginner-friendly specifications
to
- more structured engineering-style specifications.

# Learning Path

## Phase 1 — Fundamentals and Syntax

Topics:
- Variables
- Loops
- Conditionals
- Methods
- Console interaction

Examples:
- Calculator
- Fibonacci
- Prime numbers
- Palindrome checker

---

## Phase 2 — Arrays and Matrices

Topics:
- Arrays
- Matrix operations
- Searching
- Sorting

---

## Phase 3 — Object-Oriented Programming

Topics:
- Classes
- Encapsulation
- Inheritance
- Polymorphism
- Composition

Projects:
- Bank account system
- Hotel reservation system
- Mini ecommerce

---

## Phase 4 — Java APIs and String Processing

Topics:
- String manipulation
- Regex
- Date/Time API
- Maps and counters

---

## Phase 5 — Collections Framework

Topics:
- List
- Set
- Map
- Queue
- Stack
- Tree structures

---

## Phase 6 — Exceptions and Validation

Topics:
- Custom exceptions
- Validation
- Defensive programming
- Error handling

---

## Phase 7 — Files and Serialization

Topics:

## Phase 8 — Modern Java (Java 8+)

Topics:

# Rules

## Allowed

- Standard Java SDK
- Java 8+
- JUnit (later phases)

---

## Not Allowed (initial phases)

- Spring
- Hibernate
- Lombok
- Apache Commons
- External libraries
- AI-generated full solutions

# Recommended Workflow

1. Read the specification carefully.
2. Design the solution before coding.
3. Implement incrementally.
4. Refactor after completion.
5. Test manually.
6. Optimize readability.

- Understand OOP deeply

- Work with Java Streams
- Solve algorithmic problems
- Structure medium-sized applications
